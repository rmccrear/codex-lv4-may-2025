# Kata Practice (suggested: Filter Search)

[← Back to Week 1](README.md) / [← Course Index](../../README.md)

---

## Overview

Practice your React and JavaScript skills by completing any kata from the kata collection. **We suggest Kata 8: Search/Filter Names**, which focuses on the filter pattern using a for loop to search through an array of names. However, you may choose any kata that interests you or challenges your current skill level.

## Instructions

### Step 1: Choose and Complete a Kata

1. **Choose a kata** from the [kata collection](../../kata/README.md). We suggest starting with **[Kata 8: Search/Filter Names](../../kata/kata-08-filter-search.md)** if you're unsure which to pick.

2. **Read the kata instructions** for your chosen kata.

3. **Practice the kata** using CodeSandbox or your local development environment:
   - Follow the requirements specified in your chosen kata
   - Implement the solution according to the kata's instructions
   - Test your solution thoroughly

4. **If you choose Kata 8 (Filter Search), key requirements:**
   - Create a `SearchNames` component
   - Implement filtering using a **for loop** (not the `.filter()` method)
   - Make the search case-insensitive
   - Display filtered results
   - Empty search should show all names

### Step 2: Prepare for Presentation

Practice your kata solution so you can **present it live** during Week 2. You will demonstrate:
- Your working solution
- How your solution works (the logic/approach you used)
- Your code implementation

**Note:** No recording is required—this will be a live presentation.

## Submission

Submit a link to your CodeSandbox or GitHub repository with your completed kata solution.

---

**💡 Tip:** If you choose Kata 8 (Filter Search), focus on understanding the filter pattern and how to implement it with a for loop. This will help you understand array methods like `.filter()` when you encounter them later. For other katas, focus on the core concepts and patterns they teach.
